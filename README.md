# 🛡️ Security AI Agent V1

Agent d'audit de sécurité avec IA pour Termux Android

## 🚀 Fonctionnalités

- **Audit de sécurité** automatisé
- **Installation d'APK** avec analyse préalable
- **Gestion de fichiers** complète
- **Contrôle d'applications**
- **Création de comptes**
- **Apprentissage automatique**
- **Mémoire persistante** (SQLite + Vectorielle)

## 📦 Installation

```bash
# 1. Cloner le projet
git clone <repository>
cd SECURITY_AI_AGENT_V1

# 2. Lancer l'installation
bash setup.sh

# 3. Configurer l'API
nano .env
# Ajouter: OPENAI_API_KEY=votre-cle-api

# 4. Lancer l'agent
python main.py
